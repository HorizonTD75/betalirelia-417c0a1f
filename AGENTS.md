- Route metadata is owned by routeMeta and guide frontmatter; the same head helpers serve React navigation and per-route static HTML. Why: avoid stale navigation tags and duplicated SEO sources.
- Guide FAQ answers are extracted verbatim from Markdown into native details/summary and remain in the DOM even when closed. Why: accessible keyboard interaction and static export compatibility.
- Choice-loupe photo needs use a typed editorial registry and explicit layout placements over historical IMAGE_ZONE comments; a development-only context enables photo preparation, while production forces visitor mode and verified assets attach by stable zone id. Why: publication cannot expose briefs, retired zones cannot render, and photographic decisions remain independent from historical articles.
